Design Principles

Professional & Operational

Calm, dispatcher-grade information density with no decorative styling. Built for transit professionals.

Strict 8px Grid

All spacing, padding, and gaps follow multiples of 8px. Ensures consistent rhythm and alignment.

Accessible & Keyboard-Friendly

WCAG AA contrast ratios, visible focus rings, and semantic HTML for screen readers.

Component Reuse

Consistent component library used across all screens. No improvised patterns.

Fully Responsive

Adapts seamlessly across all screen sizes — desktop, tablet, and mobile devices.

State Completeness

Every collection includes empty, populated, loading, hover, and selected states.
