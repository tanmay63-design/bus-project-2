Tree Navigation

A hierarchical sidebar navigation for exploring nested data: Organizations → Depots → Routes. Supports expand/collapse, active state highlighting, inline add actions, and connecting lines between levels. Designed to sit inside the .nav-rail-body container.

    Hierarchy & Icons

    Level 0 — Organization

    Root of the tree. Expands to show depots. building-2 icon. + adds a new depot.

    Level 1 — Depot

    Child of org. Expands to show routes. warehouse icon. + adds a new route.

    Level 2 — Route

    Leaf node. No toggle or +. Uses a spacer to align with parent icons. map-pin icon.

    CSS Classes

    Class Element Purpose
    .tree-navdivScrollable wrapper that fills .nav-rail-body
    .tree-listulRoot list, no indentation
    .tree-childrenulNested list with left border (connecting line) and indentation
    .tree-children.collapsedulHides children — toggled by toggleTree()
    .tree-itemliIndividual node wrapper
    .tree-rowdivClickable row — flex, 40px min-height, hover + active states
    .tree-row.activedivCurrent page highlight — primary blue bg tint + bold label
    .tree-togglebuttonChevron expand/collapse button — rotates 90° when .open
    .tree-toggle.openbuttonExpanded state — chevron rotated down
    .tree-labelspanTruncated text label — 13px, ellipsis overflow
    .tree-addbuttonInline + button — hidden until row hover
    .tree-leaf-spacerspan16px spacer replaces toggle on leaf nodes to align icons
    .tree-add-orgbuttonRoot-level "New Organization" ghost button below the tree
    .tree-settingsdivSettings row pinned to bottom of .nav-rail-body

    Behaviour Notes

    Expand / Collapse

    Clicking the chevron toggles .collapsed on the sibling .tree-children and toggles .open on the button. Chevron rotates 90° via CSS transition.

    Inline Add

    The + button is opacity: 0 by default and fades in on row hover. It creates the next level down: org → depot, depot → route.

    Connecting Lines

    .tree-children uses border-left for the vertical line. Each .tree-row::before draws the 8px horizontal connector using --border-default.

    Scroll

    The .tree-nav div is overflow-y: auto with a 3px custom scrollbar. Header and footer remain fixed while the tree scrolls.
